## 🛠️ Built With

- **HTML5 / CSS3 / Vanilla JS** — no framework overhead, fully self-contained
- **Tailwind CSS** — utility-first styling
- **Kanit** (Google Fonts) — the display typeface driving the whole visual identity
- **IntersectionObserver** — scroll-triggered reveal animations
- **Custom scroll-linked marquee** — the experience strip moves with the page, not on a timer
- Zero build step — open the file, it just works
