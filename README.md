## 📂 Quick Start & Local Boot

Spin up a local copy of the console in under 10 seconds:

```bash
# Clone the repository
git clone https://github.com/DiyaMali/DIYA-MALI-portfolio.git

# Enter workspace
cd DIYA-MALI-portfolio

# Boot local server
python -m http.server 8080
```
Then point your browser to `http://localhost:8080` to experience the portfolio.
