## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DiyaMali/DIYA-MALI-portfolio.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd DIYA-MALI-portfolio
   ```
3. **Open the site:**
   Simply open `index.html` in any web browser, or run a local development server:
   ```bash
   # using python
   python -m http.server 8080
   ```
   Then view it at `http://localhost:8080`.
